# 医生信息搜索任务

搜索目标：

- 医生姓名：{罗文静}
- 医院名称：{ 广西壮族自治区人民医院}
- 科室名称：{神经内科}

---

## 执行步骤

1. **搜索阶段**
   - 直接访问以下医疗平台搜索医生信息（不要使用搜索引擎聚合）
   - 按优先级顺序访问：
     1. 医院官网（如有已知 URL）
     2. 好大夫在线：https://www.haodf.com
     3. 百度健康：https://health.baidu.com
     4. 39健康网：https://yyk.39.net
     5. 有来医生：https://www.youlai.cn
     6. 名医汇：https://www.mingyihui.net
   - 访问至少2个不同来源进行交叉验证

2. **验证阶段**
   - 确认医院全称是否匹配
   - 确认科室名称是否匹配
   - 确认医生确系该医院本院医生（非外聘/坐诊专家）
   - 核对职称、职务等信息一致性

3. **输出阶段**
   - 提取并结构化信息为 JSON 格式
   - 在 otherpropertys 中填写实际访问的医生详情页 URL

## 注意事项

1. **数据真实性**
   - 必须基于实际搜索结果填写，不可编造
   - 未找到的字段填 `null`
   - 多个来源信息矛盾时，优先采用医院官网数据

2. **数据准确性**
   - 医院名称需为官方全称
   - 科室名称需与医院官网一致
   - 职称需严格按照枚举值填写

3. **特殊情况处理**
   - 如医生不在指定医院，返回找到的正确医院并在 intro 开头注明："搜索显示该医生实际工作医院为：XXX"
   - 如科室不匹配，返回找到的正确科室并在 intro 开头注明："搜索显示该医生实际科室为：XXX"
   - 如信息严重缺失（少于3个字段有值），years_of_experience 返回 0

4. **从业年限计算**
   - 优先使用页面直接显示的从业年限
   - 如未显示，可从毕业年份推算：当前年份 - 毕业年份
   - 例：2020年毕业，当前2024年，则从业年限 = 2024 - 2020 = 4年
